# BarPass v6 — Every module has ONE job

│ ├── Core/
│ │ ├── Identity/IdentityEngine.swift # Orchestrator

│ │ ├── Identity/FraudDetector.swift # 6-layer fraud

│ │ ├── Biometrics/EmbeddingStore.swift # Vectors NOT photos
│ │ ├── Compliance/ConsentManager.swift # FDBR + BIPA flows
│ │ ├── Compliance/AuditLogger.swift # Tamper-evident log
│ │ ├── Security/TokenManager.swift # JWT role-based

│ ├── Integrations/

│ └── Views/
